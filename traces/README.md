# traces/

This directory contains recorded runtime traces, synthetic workload traces, and labeled datasets for `tensor_alloc`.

---

## 1. Trace Formats and Schema Version 1.1.0

Traces can be recorded directly from running applications via `tensor_trace_start()` / `tensor_trace_stop()` or generated synthetically via `python/collect_trace.py`.

### 1.1 JSON Lines Format (`.jsonl`)

The trace file begins with a metadata header:
```json
{
  "schema_version": "1.1.0",
  "trace_type": "transformer_ml_workload",
  "num_runs": 3,
  "steps_per_run": 20,
  "created_at_utc": "2026-10-21T05:22:46Z",
  "seed": 42
}
```

Followed by event records:

#### Allocation Event (`"event_type": "alloc"`)
```json
{
  "event_type": "alloc",
  "run_id": "run_001",
  "request_id": 42,
  "name": "q_proj",
  "shape": [16, 12, 128, 64],
  "ndim": 4,
  "strides": [98304, 8192, 64, 1],
  "dtype": "float16",
  "device": "cpu",
  "requested_bytes": 3145728,
  "lifetime_hint": "temporary",
  "timestamp_ns": 12458900
}
```

#### Deallocation Event (`"event_type": "free"`)
```json
{
  "event_type": "free",
  "run_id": "run_001",
  "request_id": 42,
  "timestamp_ns": 15682100
}
```

### 1.2 CSV Format (`.csv`)
Columns:
`event_type,run_id,request_id,name,shape,ndim,dtype,device,requested_bytes,lifetime_hint,timestamp_ns`
*(Shapes are semicolon-delimited, e.g. `16;12;128;64`)*

---

## 2. Units and Semantics

- **`requested_bytes`**: Authoritative requested size in bytes.
- **`strides`**: Measured in **elements** (NumPy / PyTorch convention).
- **`timestamp_ns`**: Relative nanoseconds elapsed since trace recording initialized.
- **`lifetime_hint`**: Categorical hint (`temporary`, `persistent`, or `unknown`).
- **Tensor contents**: Tensor values are never stored to prevent memory and privacy overhead.

---

## 3. Labeled Dataset Schema (`traces/labeled_dataset.json`)

Generated by `python/build_labels.py`:
- **Features (`11` dimensions)**:
  `["rank", "dim_0", "dim_1", "dim_2", "dim_3", "num_elements", "is_contiguous", "dtype_code", "lifetime_hint_code", "requested_bytes", "log2_requested_bytes"]`
- **Labeling Objectives**:
  - `baseline_class`: Smallest power-of-two size class where $\text{capacity} \ge \text{requested\_bytes}$.
  - `clustered_class`: Consolidates temporary buffers into shared classes to boost pool reuse.
  - `oracle_class`: Offline oracle matching allocations to immediately available idle blocks in the pool.
- **Split-by-Run Guarantee**:
  Data is partitioned by `run_id` (train / val / test) ensuring zero data leakage across splits.
